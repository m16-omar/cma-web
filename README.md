# City Media Academy (CMA) - Web & Mini LMS

> **"Nurturing the next generation of radio professionals and media entrepreneurs."**

Nigeria's premier broadcast, on-air presentation, voiceover, podcasting, and media entrepreneurship training academy by **Cardinal Broadcasting Limited** (affiliated with **City 105.1 FM**, **93.5 Area FM**, and **Praise in the City**).

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

---

## 🎨 Tech Stack & Branding

- **Frontend**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Theme Tokens
- **Branding**:
  - Primary Orange: `#FF6B00`
  - Deep Black: `#08090E` / `#000000`
  - Card Surface: `#131722`
  - Accent: `#FFA048`
  - Typography: Inter + Poppins
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **State Management**: Zustand
- **Routing**: React Router DOM v6
- **SEO**: React Helmet Async

## 🏆 Key Features & Dual-Mode LMS Architecture

### 1. Dual-Mode Architecture (Physical + Online + Hybrid)
- **Physical Studio Track**: Training at City 105.1 FM Broadcast Complex, Plot 11 Lateef Jakande Road, Agidingbi, Ikeja, Lagos.
- **Online Live LMS Track**: Interactive streaming, digital coursework, and session cloud replays.
- **Hybrid Track**: 2 weeks intensive 5-hour daily masterclasses + 3 weeks guaranteed on-air station internship at City 105.1 FM / 93.5 Area FM.

### 2. 8 Comprehensive Pillars
1. Radio/TV Presentation
2. Interview & Show Preparation
3. Voiceover & Audio Production
4. Diction & Speech Training
5. Social Media Management
6. Event Hosting & Public Speaking
7. Media Marketing
8. Personal Branding

### 3. Student Portal (`/dashboard`)
- My Enrolled Courses & Real-time Progress Bar
- Session Attendance Tracker with Present, Late, and Absent records
- Direct links to upcoming classes (Physical Studio vs Online Zoom room)
- 3-Week City FM Internship Assignment Status
- Verified Certificate of Competency

### 4. Facilitator Hub (`/facilitator`)
- Real-time Class Roster with attendance percentages
- 1-Click Live Attendance Marker (Present, Late, Absent)
- Session Notes & Recording Link Publisher
- Cohort performance metrics
